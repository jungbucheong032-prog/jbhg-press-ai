중부해경 홍보계 보도자료 AI 비서 7차 — 공유용 웹앱

주요 기능
- 휴대폰 최적화
- 1보 → 2보 → 3보 → 종합 단계별 작성
- 단계별 공개범위 안전장치
- 1보: 원인·상세경위·조치결과 자동 제외
- 2보: '추가 확인사항' 중심
- 3보: '확정 사고 경위·확인 원인·조치 결과' 반영
- 종합: 최종 확인 사실 종합
- 같은 사건의 단계별 버전 저장/불러오기
- 기사형 보도자료 출력
- 제목 10개 추천
- 최근 언론 제목 참고
- 대한민국 정책브리핑 해경자료 참고
- TXT 저장 / 전체 복사
- PWA 설치형 웹앱 지원(호스팅 환경에서 사용 가능)

공유 방법
1) 이 폴더 전체를 Netlify, GitHub Pages 등 정적 웹호스팅에 업로드
2) 생성된 웹 주소를 카카오톡/문자/메일로 공유
3) 휴대폰 브라우저에서 접속 후 홈 화면에 추가하면 앱처럼 사용 가능

주의
- 이 버전은 브라우저에서 동작하는 정적 웹앱입니다.
- 입력자료와 단계별 저장은 기본적으로 각 사용자의 브라우저 localStorage에 저장됩니다.
- 여러 사용자가 같은 사건의 자료를 서버에서 공동 편집하는 기능은 포함하지 않았습니다.
- 실제 배포 전 기관 내부 보안·개인정보·외부망 사용 기준을 확인하십시오.
