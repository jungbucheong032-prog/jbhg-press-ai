중부해경 홍보계 보도자료 AI 비서 8차
핵심 변경: 일시·장소·선박·인원 등을 각각 입력하지 않고 '신고접수 내용'을 한 번에 입력한 뒤 자동 인식

사용 예:
2026. 9. 15. 10:00 인천 영종도 을왕리해수욕장 서방 2해리 해상에서 모터보트(선명미상)가 전복되어 탑승자 3명이 물에 빠졌다

1. 신고접수/최초 확인 내용에 위 문장처럼 원문을 그대로 입력
2. '내용 인식하기' 클릭
3. 일시·장소·선박·인원·인명피해와 사고 유형이 자동 입력되는지 확인
4. 필요한 경우 자동 인식 결과를 직접 수정
5. 1보/2보/3보/종합 단계에 맞춰 추가 확인사항을 입력하고 보도자료 완성

주의:
- 자동 인식은 초안 작성 보조 기능이며 최종 사실확인을 대신하지 않습니다.
- 실제 사고의 미확인 정보, 개인정보, 민감한 수사정보 등은 공개 웹앱에 입력하지 않는 것을 권장합니다.
- GitHub Pages에 올릴 경우 index.html이 저장소 루트에 있어야 합니다.
